# Custom Status Bar

An i3 status bar built on [i3status-rust](https://github.com/greshake/i3status-rust): two bars (`bar-main` on DP-0, which always owns the tray, and `bar-small` on DP-2), a few custom script blocks and a Win+i toggle. (An earlier Go bar on barista.run was removed 2026-11-18; see git history.)

## Contents

- `config.toml` - block config (icons `material-nf`, colors from the scheme below), bar on DP-0
- `compact.toml` - generated by `scripts/gen-compact.sh` for the smaller DP-2 (no disk space/IO, ccusage, IP); edit config.toml and rerun
- `scripts/` - custom blocks: `freq.sh`, `ccusage.sh`, `clip.sh`, `gpu.sh`; `barcycle.sh` toggles the bars
- `scripts/test.sh` - script tests (fixtures in `testdata/`)

### Color scheme

- `good`: #6d6 (green) - normal
- `degraded`: #dd6 (yellow) - warning
- `bad`: #d66 (red) - critical
- `dim-icon`: #777 (gray) - icons

## Install

`sudo pacman -S i3status-rust ttf-nerd-fonts-symbols-mono`, then `./install.sh [--dry-run] [--no-restart] [--yes]` from the checkout (any location), as the user who runs the bar. Idempotent: pulls the repo (`--ff-only`, skipped if dirty), warns about missing tools, generates `~/.config/custom_barista/{config,compact}.toml` (tracked files stay untouched), writes the bar blocks to `bars.conf` next to the i3 config (`scripts/barsconf.sh` from `i3/bars.conf.tmpl`, keeps the current Win+i state; paths in `~/.config/custom_barista/bars.env`) and an `include` of it plus the `$mod+i` binding between `# BEGIN custom_barista` / `# END custom_barista`. Old `bar {}` blocks are shown and removed only on `y`. The config is backed up (`config.bak-<date-time>`, `bars.conf.bak-<date-time>`), checked with `i3 -C` (restored on failure) and i3 is restarted. A saved state `barista` from the old Go bar is treated as `rs`.

Runtime deps (`install.sh` warns about missing ones): `i3status-rs`, a Nerd symbols font; used by blocks and click actions `jq`, `xclip`, `node`/`npx` (ccusage), `nvidia-smi`, `xdotool`, `pavucontrol`; optional `yad` (calendar/clipboard popups); `~/scripts/clipboard_menu.sh` and `open_calender.sh` (not in this repo).

## Win+i

Toggles off <-> i3status-rust. `barcycle.sh` rewrites `bars.conf` for the next state (both bars switch `mode` and `status_command`), checks `i3 -C` (restores on failure) and runs `i3-msg reload`; the state survives an i3 restart. The tray never moves to another i3bar process (that lost icons); presses are serialized with a lock. If a bar ever freezes after very fast switching, `i3-msg restart` recovers it.
